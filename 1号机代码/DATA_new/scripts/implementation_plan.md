## M1: D1 覆盖曲线重做

### 问题
当前 D1 是每组一张图（含 L0/L1/L2 三条线），共 4 组。老师要求拆成独立的 9 张图（S*L0, S*L1, S*L2, M*L0, ...），并且需要两套横坐标。

### 修正方案

#### 第一套：横坐标 = Budget%（归一化）
- 保留现有逻辑，但拆成 **3组 x 3级 = 9 张独立子图**。
- X 轴 = 0% ~ 100%（每帧的题量归一化到 [0,1]）。

#### 第二套：横坐标 = 真实题数（绝对值）
- X 轴 = 实际生成的问题数量（整数）。
- **关键处理**：由于每帧题量不统一，需要做"截断补齐"：
  - 假设某帧总共生成了 $Q_i$ 道题。
  - 当横坐标 $x > Q_i$ 时，该帧的覆盖率按 **100%** 计算（即认为该帧已满覆盖）。
  - 最终对所有帧取平均，得到 `avg_coverage(x)`。
  - X 轴上限取 P90 或 P95 的帧题量，避免被极端大帧拉长。

#### 输出
- 共 **18 张图**（9 Budget% + 9 真实题数）。
- 每张图标注 AUC 值。

### 涉及文件
- `plot_rq2_grouped.py` -> 重写 `plot_grouped_absolute()` 和 `plot_grouped_normalized()`。

## M2: D2 覆盖衰减深化（合并 D4/8/10/12/16）

### 问题
D2、D4（压缩率）、D8（冗余度）、D10（约束质量）、D12（图密度）、D16（饱和成本）本质上在说同一件事 ---- "每道题的边际贡献随生成进度如何变化"。老师要求：
1. 只保留 D2 作为核心维度。
2. 将 D2 做到足够深入，使其能一并涵盖 D4/8/10/12/16 的结论。
3. 改掉"占比式"的不直观表达，改为**平均每题贡献几个 Gap**。
4. 不只看 L2，**L0、L1 也要放进来**，实现横向（L0 vs L1 vs L2）和纵向（生成进度递进）的双维度分析。

### 修正方案

#### 新 D2 指标定义
对于覆盖进度的每个区间段（例如 0-10%, 10-20%, ..., 90-100%），计算：

$$\text{Avg Gap Contribution per Question} = \frac{\Delta \text{Coverage}_{L_k} \times \text{Total Gaps}_{L_k}}{\Delta Q}$$

其中 $L_k \in \{L0, L1, L2\}$。

#### 新 D2 表格结构

| 覆盖进度 | L0: Gaps/Q | L1: Gaps/Q | L2: Gaps/Q | 备注 |
|----------|-----------|-----------|-----------|------|
| 0%-10% | ... | ... | ... | 早期高效阶段 |
| 10%-25% | ... | ... | ... | |
| 25%-50% | ... | ... | ... | 分界点附近 |
| 50%-75% | ... | ... | ... | |
| 75%-90% | ... | ... | ... | |
| 90%-100% | ... | ... | ... | 长尾阶段 |

#### 新 D2 需要涵盖的结论（替代 D4/8/10/12/16）
1. **压缩率 (原 D4)**：从"早期阶段 Gaps/Q > 1"可以直接得出压缩率 < 1 的结论。
2. **冗余度 (原 D8)**：从"Gaps/Q 随进度下降"的幅度可以推算出冗余度。
3. **约束质量 (原 D10)**：在分析中补充"带约束题型 vs 无约束题型"的 Gaps/Q 对比。
4. **图密度 (原 D12)**：按 S/M/L 分组后，Gaps/Q 的绝对值差异直接反映图密度影响。
5. **饱和成本 (原 D16)**：最后 10% 区间的 Gaps/Q 与前 10% 的比值即为长尾代价。

#### 可视化
- **主图**：折线图，X = 覆盖进度区间，Y = Avg Gaps/Q，三条线分别代表 L0/L1/L2。
- **分组**：S/M/L 各一张，共 3 张。
- **辅助图**：堆叠柱状图，展示各区间内不同题型的贡献占比。

### 涉及文件
- 新建分析脚本 `analyze_d2_deep.py`。
- 删除独立的 D4/D8/D10/D12/D16 分析逻辑（合并进 D2）。

## M3: D3 生成逻辑重构（核心代码重写）

### 问题
当前的 R1/R2 两轮设计存在以下问题：
1. **叙事复杂**：论文中需要解释两轮的动机、分工、衔接，增加了审稿人的理解成本。
2. **题型不均衡**：R1 只有 converge + diverge，R2 只有 chain + viewpoint，导致题型分布不自然。
3. **实际观察**：从数据来看，大约在覆盖了 **1/4 的 Gap** 之后，即使是 converge/diverge 这种"高覆盖力"题型，其边际贡献也已经趋近于 1 Gap/Q。

### 修正方案：单轮混合策略

#### K 值定义
- **K = 分界点覆盖率百分比**。当已覆盖的 L2 Gap 数量达到 `K% x total_gaps` 时，从 Phase 1 切换到 Phase 2。
- 初步估计 K=25%（基于观察：约在覆盖 1/4 Gap 后，converge/diverge 的边际贡献趋近于 1 Gap/Q）。
- **需要实验确定**：跑多个 K 值（10%, 15%, 20%, 25%, 30%, 35%），找到边际贡献拐点。

#### 新生成逻辑

```
Phase 1 (coverage < K% of total_gaps):
    - 仅使用 converge + diverge_compare（带约束的高覆盖力题型）
    - 贪心选择：每次选覆盖增量最大的 plan
    - 目的：快速压缩覆盖空间

Phase 2 (coverage >= K% -> 100%):
    - 四个等量槽位，使用"最小计数优先"策略：
      Slot A: converge+diverge（优先 diverge，不可行回退 converge）
      Slot B: direction_chain
      Slot C: distance_chain
      Slot D: viewpoint_transfer
    - 每次选当前累计生成最少的槽位，保证四槽平衡
    - 仍然追踪 delta_l2，已覆盖 Gap 从池中移除
    - 如所选槽位对当前 Gap 不可行，按计数升序 fallback
    - 目的：保证题型丰富度 + 完成满覆盖
```

#### Phase 2 实现伪代码

```python
slot_counts = {"A": 0, "B": 0, "C": 0, "D": 0}

for gap in uncovered_gaps:
    # 选当前计数最小的槽位（相同时随机打破）
    min_count = min(slot_counts.values())
    candidates = [s for s, c in slot_counts.items() if c == min_count]
    slot = random.choice(candidates)
    
    qa = try_slot(slot, gap)  # Slot A: try diverge first, then converge
    if qa is None:
        # fallback: 按计数升序尝试其他槽位
        for fb in sorted(slot_counts, key=slot_counts.get):
            if fb == slot: continue
            qa = try_slot(fb, gap)
            if qa: slot = fb; break
    
    if qa:
        slot_counts[slot] += 1
        emit(qa)
        mark_covered(gap)  # 更新 delta_l2, 从 pool 移除
```

#### 四槽设计说明

| 槽位 | 题型 | 内部逻辑 | 目标占比 |
|------|------|----------|----------|
| **Slot A** | converge + diverge | 优先尝试 diverge，不可行则回退 converge | ~25% |
| **Slot B** | direction_chain | 直接生成 | ~25% |
| **Slot C** | distance_chain | 直接生成 | ~25% |
| **Slot D** | viewpoint_transfer | 直接生成 | ~25% |

> diverge 可行率极低（当前 0.01%~0.44%），单独设槽不现实。
> 合并入 converge 槽，可行时优先用 diverge，实现"能用就用"。

#### 与旧逻辑的对比

| 维度 | 旧逻辑 (R1+R2) | 新逻辑 (单轮混合) |
|------|----------------|-------------------|
| 轮次 | 两轮，R2 遍历全部 Gap | 单轮，一次性完成 |
| R1 题型 | converge + diverge | Phase1: converge + diverge |
| R2 题型 | chain + viewpoint (每 Gap 一题) | Phase2: 四槽等量（最小计数优先） |
| 题型均衡 | 不均衡（R2 题量远超 R1） | 均衡（四槽自平衡） |
| 论文叙事 | 需要解释两轮动机 | 简洁：先压缩后丰富 |
| 总题量 | R2 为每个 Gap 都生成 -> 极大 | Phase2 只为未覆盖 Gap 生成 -> 显著减少 |
| delta_l2 追踪 | R2 不追踪 | Phase2 仍追踪，已覆盖 Gap 移除 |

#### 补充分析：每种题型的 Gap 贡献能力
在新逻辑跑完后，需要统计：
- 每种题型在 Phase 1 中的平均 Gaps/Q。
- 每种题型在 Phase 2 中的平均 Gaps/Q。
- 各题型的"可行率"（feasibility rate）：对于随机选中的 Gap，该题型能成功生成的概率。
- 四槽最终实际计数与偏差。

### 涉及文件
- **核心修改**：`run_gap_pipeline_v7.py` 的 L2000-L2160 区域（删除 R2 遍历逻辑，改为单轮混合）。
- **新增**：K 值扫描实验脚本。
- **离线部分不动**：`precompute`、`plan_cache` 等前置阶段保持不变。

## M5: D11 Ego 平等化

### 问题
当前实现中，Ego 车辆在某些约束规划逻辑中被特殊处理（例如不能作为 A/B/C 中的某个位置）。老师要求：
- **取消 Ego 的特殊地位**，将其与所有其他节点完全平等对待。
- **优势**：Ego 作为 A 或 C 端时，由于其位置是确定的（相机原点），无需额外的方位约束即可唯一指代，反而简化了约束规划。

### 修正方案
1. 在 `l2_constraint_planner.py` 中，移除对 `obj_type == "ego"` 的特殊分支或跳过逻辑。
2. 在 Gap 枚举阶段，确保 Ego 节点可以出现在 A/B/C 的**任意位置**（包括 B 作为中间枢纽）。
3. 在约束规划中，当 Ego 作为 A 或 C 时，跳过 `ref_dir` 约束的添加（因为 Ego 本身就是唯一的，无需消歧）。
4. Ego 作为 B（中间枢纽）时正常处理，不做特殊豁免。

### 涉及文件
- `run_gap_pipeline_v7.py`：Gap 枚举部分。
- `gap_pipeline/l2_constraint_planner.py`：约束规划逻辑。
- `gap_pipeline/l2_question_realizer.py`：问题模板中对 Ego 的特殊措辞。
