### 1. Count 类（计数统计）—— 约 20%



这类题目不仅仅是“数数”，根据约束条件的复杂度，可以细分为：

- **全局计数 (Global Counting):**
  - *例题:* "How many cars are there in total?"
  - *考点:* 考察模型对整个场景的物体检测召回率。
- **特定属性计数 (Attribute-Specific Counting):**
  - *例题:* "How many **moving** trucks are there?"
  - *考点:* 考察检测+属性识别（动/静）。
- **空间约束计数 (Spatial Counting):**
  - *例题:* "How many pedestrians are **on the left** of the ego vehicle?"
  - *考点:* 考察对自车坐标系和方位的理解。



### 2. Exist 类（存在性判断）—— 约 30%



这是占比最大的（也是最简单的），本质是**二分类（Binary Classification）**，但也有细分：

- **绝对存在性:**
  - *例题:* "Are there any bicycles in the scene?"
- **空间存在性:**
  - *例题:* "Is there a car **behind** us?"
- **复合条件存在性:**
  - *例题:* "Is there a **stopped** bus **in front**?"
  - *注意:* 这类题目回答是 Yes/No，是模型“刷分”的重灾区（容易瞎猜），但在实际自动驾驶中对安全性检测很重要。



### 3. Comparison 类 (比较推理) —— 约 15%



这类题目需要模型同时处理两组信息并进行逻辑比较，属于**高阶推理**：

- **数量比较 (Count Comparison):**
  - *例题:* "Are there **more** cars **than** pedestrians?"
  - *逻辑:* $Count(A) > Count(B)$ ?
- **状态比较 (State Comparison):**
  - *例题:* "Are there more **moving** objects than **stationary** objects?"



### 4. Object 类 (物体识别/指代) —— 约 20%



这类题目通常是“填空题”，问的是类别（Category）。它需要模型先**定位**（Grounding），再**分类**。

- **最近/最远物体识别:**
  - *例题:* "What is the **closest** object to the ego vehicle?"
  - *考点:* 深度/距离感知 + 物体分类。
- **特定方位物体识别:**
  - *例题:* "What is the object **on the front-left**?"
- **答案集:** 从你的截图中可以看到，这类题目的答案通常是 `car`, `pedestrian`, `truck`, `bus` 等名词。



### 5. Status 类 (状态/动作查询) —— 约 14%



这类题目问的是物体的**行为**或**属性**，而不是类别。

- **运动状态查询 (Motion State):**
  - *例题:* "Is the car on the left **moving** or **stopped**?"
  - *答案集:* 你的截图里显示 `moving` 是热门答案之一，就属于这一类。
- **交通状态查询 (Traffic State):**
  - 某些复杂的 NuScenes-QA 变种可能包含对红绿灯状态的查询（但在标准版中较少，主要集中在物体行为）。



# MetaVQA结构

![MetaVQA结构解析](E:\Project\ADVTEST\成果记录\MetaVQA结构解析.png)

![image-20251127152739777](C:\Users\91852\AppData\Roaming\Typora\typora-user-images\image-20251127152739777.png)

根据 MetaVQA 数据集提供的这 30 种题型（Type），结合自动驾驶（Autonomous Driving）的感知、规划和推理逻辑，可以将它们归纳为以下 **四大核心类别**。

这种分类方式适合你在论文或技术报告中描述数据集的构成：



### 1. 具身与反事实推理类 (Embodied & Counterfactual Reasoning)



这是 MetaVQA 最独特也是占比最高的部分（前三名），主要考察模型在**自我车辆（Ego-vehicle）**执行特定动作后的状态推演。

- **核心逻辑：** “如果我执行了动作 X，会发生什么？”
- **包含题型：**
  - `embodied_sideness`: 动作后的方位判断。
  - `embodied_distance`: 动作后的距离变化。
  - `embodied_collision`: 动作后是否会碰撞。



### 2. 安全与风险预测类 (Safety & Critical Prediction)



这类题目直接关联自动驾驶的安全性，考察模型对动态和静态障碍物潜在风险的预判能力。

- **核心逻辑：** “是否有碰撞风险？是谁导致的？”
- **包含题型：**
  - `predict_crash_ego_still`: 自车静止时的碰撞预测。
  - `predict_crash_ego_dynamic`: 自车运动时的碰撞预测。
  - `relative_predict_crash_dynamic`: 相对动态碰撞预测。
  - `relative_predict_crash_still`: 相对静态碰撞预测。



### 3. 空间关系与逻辑推理类 (Spatial Reasoning & Logic)



这类题目不只是识别物体，更重要的是理解物体之间的**相对位置**、**顺序**以及**比较**。这是图神经网络（Graph Neural Networks）最擅长的部分。

- **核心逻辑：** “谁离我最近？A 在 B 的哪边？排在最前面的是谁？”
- **包含题型：**
  - **比较 (Comparison):** `pick_closer` (选更近的), `relative_distance`, `relative_position`, `relative_heading`。
  - **排序与极值 (Ordering & Superlatives):** `order_frontmost`, `identify_backmost`, `order_rightmost`, `order_leftmost`, `identify_frontmost`, `order_backmost`, `identify_closest`, `identify_rightmost`, `identify_leftmost`, `order_closest`。
  - **定位 (Grounding):** `grounding` (视觉定位/指代)。



### 4. 基础感知与场景描述类 (Basic Perception & Description)



这是最基础的 VQA 任务，考察模型对场景中物体属性的识别能力以及对宏观场景的理解。

- **核心逻辑：** “那是什么颜色？那个物体多远？这是什么场景？”
- **包含题型：**
  - **属性识别 (Attribute Identification):** `identify_type` (种类), `identify_position`, `identify_distance`, `identify_heading` (朝向), `identify_color`。
  - **场景描述 (Scene Description):** `describe_distance`, `describe_sector` (区域描述), `describe_scenario` (场景类型描述)。





1. **侧重规划（Planning-Oriented）：** 从数量上看，**具身推理类**（Category 1）占据了绝大多数数据（前三名加起来占了约 35%），这说明 MetaVQA 与传统 VQA 不同，它非常强调**Action-Conditioned（动作条件化）**的推理。
2. **空间敏感（Spatially Aware）：** 包含大量的排序（Order）和相对关系（Relative）题目，这验证了为什么这个数据集适合用**场景图（Scene Graph）**来解决，因为图结构天然适合处理节点间的关系。
3. **长尾分布：** 虽然题型多达 30 种，但后半部分（主要是细粒度的排序和属性识别）数据量分布比较均匀且稀疏，核心任务还是集中在头部。

# 生成场景图实现

## 每个环节的数据类型与关注重点

### 环节1：原始数据 → 场景图

```
输入：sample_annotation.json（人工标注）
输出：nuscenes_scene_graph_mini_v2.jsonl（结构化场景图）

关注重点：
✅ 坐标系变换是否正确（全局→自车）
✅ 地图挂接是否成功（on_lane_id 不为空）
✅ 空间分档是否合理（sector8, distance）
```

### 环节2：场景图 → 覆盖率统计

```
输入：场景图 JSONL
输出：coverage_*.csv（覆盖率报表）

关注重点：
✅ 哪些类别/扇区/距离档数量不足
✅ 是否有路口场景（intersecting 关系）
✅ 车道关系是否正确（same_lane 不全为 False）
```



### 环节3：场景图 → 测试用例

```
输入：场景图 JSONL
输出：qa_*.jsonl（问答对）

关注重点：
✅ 问题类型是否多样化（距离、方位、碰撞、计数）
✅ 答案是否有标准依据（来自场景图的事实）
✅ 可解释性标签（source_mr）是否完整
```

### 环节4：场景图 → 可视化

```
输入：场景图 JSONL
输出：BEV图像、马赛克图像

关注重点：
✅ 图像是否与数据一致（框的位置、连线的关系）
✅ 颜色编码是否清晰（不同类别、不同关系类型）
✅ 是否便于人工验证（发现数据错误）
```

def world_to_ego(p_w, R_ge, t_ge):
    """
    全局坐标 → 自车坐标系
    
    参数:
        p_w: 全局坐标点 [x, y, z]
        R_ge: 自车旋转矩阵
        t_ge: 自车平移向量
    
    返回:
        自车坐标系下的点
    """
    return R_ge.T @ (p_w - t_ge)

```python
def get_s3c_angular(bearing):
    """
    S3C角度分档 (4档)
    
    分档策略:
    - direct_front: [-π/4, π/4]
    - side_front: [π/4, 3π/4]
    - direct_rear: [3π/4, 5π/4]
    - side_rear: [5π/4, 7π/4]
    """
    phi = abs(bearing)
    if phi <= math.pi/4 or phi >= 7*math.pi/4:
        return 'direct_front'
    elif phi <= 3*math.pi/4:
        return 'side_front'
    elif phi <= 5*math.pi/4:
        return 'direct_rear'
    else:
        return 'side_rear'
```

def T_from_qt(q, t):
    """构建 4x4 变换矩阵"""
    R = Quaternion(q).rotation_matrix
    T = np.eye(4)
    T[:3, :3] = R
    T[:3, 3] = np.asarray(t, dtype=float)
    return T, R, np.asarray(t, dtype=float)


def world_to_ego(p_w, R_ge, t_ge):
    """世界坐标 -> 自车坐标: R.T @ (p_w - t)"""
    return R_ge.T @ (p_w - t_ge)


def central_diff(pos_prev, t_prev, pos_next, t_next):
    """中心差分法计算速度"""
    dt = max(1e-6, (t_next - t_prev))
    return (pos_next - pos_prev) / dt


def yaw_from_q(q):
    return Quaternion(q).yaw_pitch_roll[0]


def angle_diff(a2, a1):
    """计算最小角度差 [-pi, pi]"""
    d = a2 - a1
    while d > math.pi:
        d -= 2 * math.pi
    while d < -math.pi:
        d += 2 * math.pi
    return d


def get_sample_ego_T(nusc, sample_token):

def classify_sector8(bearing_rad):
    """通用8方位划分"""
    ang = ((bearing_rad + math.pi) % (2 * math.pi)) - math.pi
    boundaries = [-7*math.pi/8, -5*math.pi/8, -3*math.pi/8, -math.pi/8, math.pi/8, 3*math.pi/8, 5*math.pi/8, 7*math.pi/8]
    names = ['back-right', 'right', 'front-right', 'front', 'front-left', 'left', 'back-left', 'back']
    for b, name in zip(boundaries, names):
        if ang <= b:
            return name
    return 'back'


def classify_s3c_angular(bearing_rad):
    """S3C 专用方位划分：区分 正向(Direct) 和 侧向(Side)"""
    angle_deg = math.degrees(bearing_rad)
    angle_deg = (angle_deg + 360) % 360
    
    if 315 <= angle_deg or angle_deg < 45: return "direct_front"
    elif 45 <= angle_deg < 135: return "side_front" 
    elif 135 <= angle_deg < 225: return "direct_rear"
    else: return "side_rear"


def s3c_distance_bin(d):
    """S3C 距离分级 (关注 <4m 的高危区)"""
    if d < 2.0: return "safe_hazard"    # 极近/碰撞风险
    elif d < 4.0: return "near_coll"    # 紧急制动区
    elif d < 7.0: return "super_near"
    elif d < 10.0: return "very_near"
    elif d < 16.0: return "near"
    elif d < 25.0: return "visible"
    elif d < 50.0: return "far"         # 感知边缘

def parse_attributes(nusc, ann):

        try:

        except Exception:
            continue
        for key in result:
            if key in name:

    return result


def est_inst_state(nusc, ann):
    """利用前后帧差分，计算世界坐标系下的速度与加速度"""
    def center_time(a):
        p = np.asarray(a['translation'], dtype=float)
        st = nusc.get('sample', a['sample_token'])
        sd = nusc.get('sample_data', st['data']['LIDAR_TOP'])
        return p, sd['timestamp'] / 1e6

    p_c, t_c = center_time(ann)
    v_w = np.zeros(3, dtype=float)
    a_w = np.zeros(3, dtype=float)

    if ann['prev'] and ann['next']:
        ap = nusc.get('sample_annotation', ann['prev'])
        an = nusc.get('sample_annotation', ann['next'])
        p_p, t_p = center_time(ap)
        p_n, t_n = center_time(an)
        v_w = central_diff(p_p, t_p, p_n, t_n)
        dt = (t_n - t_p) / 2.0
        a_w = (p_n - 2 * p_c + p_p) / max(1e-6, dt * dt)
    return p_c, t_c, v_w, a_w


# --- 场景图构建主流程 ---

def build_scene_graph_for_sample(nusc, sample_token, nusc_map=None, compute_bins=True, graph_radius=60.0, min_ttc_dist=1.0, min_closing_speed=0.1, map_cache=None):
    # 1. 自车状态计算
    T_ge, R_ge, t_ge, ts = get_sample_ego_T(nusc, sample_token)
    
    s = nusc.get('sample', sample_token)
    s_prev = nusc.get('sample', s['prev']) if s['prev'] else None
    s_next = nusc.get('sample', s['next']) if s['next'] else None

    # 计算自车 ego 速度 (代码略，逻辑同 central_diff)
    def ego_state(sample):
        sd = nusc.get('sample_data', sample['data']['LIDAR_TOP'])
        ep = nusc.get('ego_pose', sd['ego_pose_token'])
        p = np.asarray(ep['translation'], dtype=float)
        yaw = yaw_from_q(ep['rotation'])
        t = sd['timestamp'] / 1e6
        return p, yaw, t

    p0, yaw0, t0 = ego_state(s)
    if s_prev and s_next:
        p1, yaw1, t1 = ego_state(s_prev)
        p2, yaw2, t2 = ego_state(s_next)
        v_ego_w = central_diff(p1, t1, p2, t2)
        yaw_rate = angle_diff(yaw2, yaw1) / max(1e-6, (t2 - t1))
    else:
        v_ego_w = np.zeros(3, dtype=float)
        yaw_rate = 0.0

    w_ego_w = np.array([0.0, 0.0, yaw_rate], dtype=float)
    w_ego_e = R_ge.T @ w_ego_w

    nodes = []
    edges = []

    # 添加 Ego 节点
    nodes.append({
        'id': 'ego',
        'category_name': 'vehicle.ego',
        'pose': {'ego': {'center': [0.0]*3, 'yaw': 0.0}, 'global': {'center': t_ge.tolist()}},
        'velocity': {'ego': [0.0]*3, 'global': v_ego_w.tolist()},
        'size': None, 'corners_ego': None
    })

    # 2. 遍历并处理所有 Annotation
    for ann_token in s['anns']:
        ann = nusc.get('sample_annotation', ann_token)
        p_w, t_c, v_w, a_w = est_inst_state(nusc, ann)

        # 坐标转换：World -> Ego
        p_e = world_to_ego(p_w, R_ge, t_ge)
        
        q_w = Quaternion(ann['rotation'])
        yaw_e = yaw_from_q((Quaternion(matrix=R_ge.T) * q_w).elements)
        v_rel_e = R_ge.T @ (v_w - v_ego_w) - np.cross(w_ego_e, p_e)

        size_wlh = ann['size']
        box = Box(center=p_w, size=size_wlh, orientation=q_w)
        corners_e = (R_ge.T @ (box.corners().T - t_ge).T).T

        # 地图查询 (Map Attachment) - 带缓存
        on_layer, on_lane_id, in_intersection = None, None, None
        if nusc_map:
            try:
                cache_key = f"{p_w[0]:.1f},{p_w[1]:.1f}"
                if map_cache and cache_key in map_cache:
                    cached = map_cache[cache_key]
                    on_layer, on_lane_id, in_intersection = cached['layer'], cached['lane_id'], cached['in_intersection']
                else:
                    # 优先查 Lane，其次查 Lane Connector
                    lane_tok = nusc_map.record_on_point(float(p_w[0]), float(p_w[1]), 'lane')
                    if lane_tok:
                        on_layer, on_lane_id, in_intersection = 'lane', lane_tok, False
                    else:
                        layers = nusc_map.layers_on_point(float(p_w[0]), float(p_w[1]))
                        if 'lane_connector' in layers:
                             # 简化处理，取第一个 connector
                            recs = nusc_map.get_records_in_radius(float(p_w[0]), float(p_w[1]), 2.0, ['lane_connector'])
                            if recs['lane_connector']:
                                on_layer, on_lane_id, in_intersection = 'lane_connector', recs['lane_connector'][0], True
                        
                        # 回退：查最近车道
                        if not on_lane_id:
                            lane_closest = nusc_map.get_closest_lane(float(p_w[0]), float(p_w[1]), radius=10.0)
                            if lane_closest:
                                on_layer, on_lane_id, in_intersection = 'lane', lane_closest, False

                    if map_cache is not None:
                        map_cache[cache_key] = {'layer': on_layer, 'lane_id': on_lane_id, 'in_intersection': in_intersection}
            except Exception:
                pass

        attrs = parse_attributes(nusc, ann)

        dist = float(np.linalg.norm(p_e[:2]))
        if dist > 50.0: continue  # S3C 截断阈值

        bearing = math.atan2(p_e[1], p_e[0])
        
        # S3C Binning 
        sector8 = classify_sector8(bearing) if compute_bins else None
        s3c_angular = classify_s3c_angular(bearing) if compute_bins else None
        s3c_distance = s3c_distance_bin(dist) if compute_bins else None

        nodes.append({
            'id': ann['token'],
            'instance_token': ann['instance_token'],
            'category_name': ann['category_name'],
            'pose': {
                'ego': {'center': p_e.tolist(), 'yaw': float(yaw_e)},
                'global': {'center': p_w.tolist()}
            },
            'velocity': {'ego': v_rel_e.tolist(), 'global': v_w.tolist()},
            'size': {'wlh': size_wlh},
            'corners_ego': corners_e.tolist(),
            'map': {'on_layer': on_layer, 'on_lane_id': on_lane_id, 'in_intersection': in_intersection},
            'attributes': attrs,
            'bins': {
                'sector8': sector8, 
                'distance': s3c_distance_bin(dist) if compute_bins else None, # 注意这里用了 distance_bin 还是 s3c_distance
                's3c_angular': s3c_angular,
                's3c_distance': s3c_distance
            }
        })

    # 3. 边的构建 (Relation)
    id_to_node = {n['id']: n for n in nodes}
    ids = [n['id'] for n in nodes]

    for i in range(len(ids)):
        for j in range(i + 1, len(ids)):
            ni, nj = id_to_node[ids[i]], id_to_node[ids[j]]
            
            # 仅处理非自车节点，且距离 graph_radius 内
            if ni['id'] == 'ego' or nj['id'] == 'ego': continue # 视需求保留或移除ego边

            pi = np.asarray(ni['pose']['ego']['center'])
            pj = np.asarray(nj['pose']['ego']['center'])
            delta = pj - pi

            if np.linalg.norm(delta) > min(graph_radius, 50.0): continue

            # 计算关系类型 (Lateral vs Longitudinal)
            bearing_rel = math.atan2(delta[1], delta[0])
            phi = abs(bearing_rel)
            
            relation_type = 'lateral'
            if (ni['map']['in_intersection']) or (nj['map']['in_intersection']):
                relation_type = 'intersecting'
            elif (phi <= math.pi/4 or phi >= 3*math.pi/4):
                relation_type = 'longitudinal'

            # TTC 计算
            ttc = None
            vi = np.asarray(ni['velocity']['ego'])
            vj = np.asarray(nj['velocity']['ego'])
            rel_v = vj - vi
            dist_rel = np.linalg.norm(delta)
            if dist_rel > min_ttc_dist:
                u = delta / dist_rel
                closing = -float(np.dot(rel_v, u))
                if closing > min_closing_speed:
                    ttc = dist_rel / closing

            # 同车道判定
            same_lane = False
            if ni['map']['on_lane_id'] and nj['map']['on_lane_id']:
                same_lane = (ni['map']['on_lane_id'] == nj['map']['on_lane_id'])

            edges.append({
                'from': ni['id'],
                'to': nj['id'],
                'relation_type': relation_type,
                'same_lane': same_lane,
                'ttc': ttc,
                'distance': float(dist_rel)
            })

    return {'sample_token': sample_token, 'timestamp': int(ts), 'nodes': nodes, 'edges': edges}

import re

class VQAEvaluator:
    @staticmethod
    def normalize_text(text):
        """
        官方 VQA 文本归一化标准函数
        作用：让 "Yes." == "yes" == "  YES "
        """
        if not isinstance(text, str):
            return ""
        
        # 1. 转小写
        text = text.lower()
        
        # 2. 移除标点符号 (保留数字和字符)
        # 比如 "car." -> "car", "pedestrian?" -> "pedestrian"
        text = re.sub(r"[^a-z0-9 ]", "", text)
        
        # 3. 移除多余空格
        text = text.strip()
        
        return text

    @staticmethod
    def compute_accuracy(predictions, ground_truths):
        """
        计算准确率
        predictions: 模型输出的 list, 如 ["yes", "car", "0"]
        ground_truths: 标签 list, 如 ["yes", "bus", "0"]
        """
        if len(predictions) != len(ground_truths):
            print(f"警告: 预测数量 ({len(predictions)}) 与 GT 数量 ({len(ground_truths)}) 不一致!")
        
        correct = 0
        total = len(ground_truths)
        
        for pred, gt in zip(predictions, ground_truths):
            norm_pred = VQAEvaluator.normalize_text(pred)
            norm_gt = VQAEvaluator.normalize_text(gt)
            
            # 调试打印：如果你发现分特别低，把下面这行注释打开，看看是不是格式问题
            # if norm_pred != norm_gt:
            #     print(f"Wrong: Pred='{norm_pred}' | GT='{norm_gt}'")
            
            if norm_pred == norm_gt:
                correct += 1
                
        return correct / total * 100

# === 使用示例 ===
