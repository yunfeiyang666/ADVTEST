## 完成后合并

所有任务完成后，需要合并三个服务器的 CSV 文件：
```bash
# 下载所有 CSV
scp yunyang@10.16.120.6:~/ADVTEST/DATA_new/csv_output/*.csv ./server1/
scp yunyang@10.16.120.7:~/ADVTEST/DATA_new/csv_output/*.csv ./server2/
# Server 3 手动复制

# 合并（去除重复表头）
cat server1/question_answer_our.csv > merged_question_answer_our.csv
tail -n +2 server2/question_answer_our.csv >> merged_question_answer_our.csv
tail -n +2 server3/question_answer_our.csv >> merged_question_answer_our.csv
```
