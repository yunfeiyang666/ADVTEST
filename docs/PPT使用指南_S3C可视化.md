```

3. "7-10米是决策关键距离，影响变道、转向等操作"
```

```
单例聚类占比高达98%，这个数字远超S3C论文在CARLA
仿真数据上的50%，充分说明了真实世界的复杂性。"
```

### 技巧2：视觉引导
```
在展示图表时：
1. 先指出整体趋势（红色累积曲线）
2. 再强调关键点（蓝色散点的分布）
3. 最后点明发现（虚线标注的单例区域）
```

### 技巧3：建立对比
```
始终与已知的事物建立对比：
• S3C官方实验 vs 我们的实验
• 仿真数据 vs 真实数据
• 传统方法 vs S3C方法
```

### 技巧4：预判问题
```
老师可能的问题：

Q1: "为什么单例这么多？"
A: "因为S3C签名非常细粒度，即使距离相差几米也会产生
    不同的签名。这恰恰说明了真实场景的微妙变化。"

Q2: "这个结果有什么意义？"
A: "一是验证了真实数据的复杂性；二是说明了传统采样
    方法的局限；三是为覆盖率驱动的测试生成提供了依据。"

Q3: "能否降低聚类数？"
A: "可以。我们可以使用更粗粒度的签名，比如只考虑
    类别组合而忽略位置，聚类数会降到50-100。"
```
