## 📊 Slide 3: S3C的谓词抽象（重点！）

**论文图示：**
![角度关系定义](文献/s3c-main/images/relationships.png)
*来源：S3C论文，展示Direct Front/Side Front/Direct Rear/Side Rear的划分*

```
标题：从坐标到谓词 - S3C的核心创新
论文依据：Section 3.2.2 (Abstraction)

传统方法 vs S3C方法：

❌ 传统：存储精确坐标
   Car_1 = {x: 10.523, y: -3.214, z: 0.0}
   Car_2 = {x: 10.619, y: -3.108, z: 0.0}
   → 两个场景被认为不同（坐标不同）

✅ S3C：存储谓词真值
   Car_1 = {IsFront: True, IsNear: True}
   Car_2 = {IsFront: True, IsNear: True}
   → 两个场景被认为相同（空间配置相同）

谓词定义示例（来自README.md）：
┌─────────────────────────────────────┐
│ IsFront(obj):   角度 ∈ [-45°, 45°]  │ ← Direct Front (DF)
│ IsNear(obj):    距离 < 10m          │ ← very_near + near
│ IsLeft(obj):    在左侧              │ ← 左右关系
│ IsMoving(obj):  速度 > 0.5m/s       │ ← 属性谓词
└─────────────────────────────────────┘

距离档位（论文Table, README第138-148行）：
• near_coll:  ≤ 4m
• super_near: 4-7m
• very_near:  7-10m
• near:       10-16m
• visible:    16-25m

组合谓词 = 场景签名：
"IsFront & IsNear & IsMoving : Car"
→ "前方近距离有一辆移动的车"
```

## 🎯 讲解话术（30秒电梯演讲）

### **版本A：理论导向**
> "S3C的核心是**基于谓词的场景抽象**。它不存储精确坐标，而是将连续的物理状态离散化为谓词真值，比如'前方有车且距离很近'。这样做的好处是可以进行**覆盖率查询**：通过图同构聚类，统计每种空间配置的出现次数，识别测试盲区。我们的实验发现，NuScenes的98%场景是独特配置，验证了S3C覆盖率度量的必要性。"

### **版本B：应用导向**
> "S3C解决的核心问题是：**如何量化自动驾驶测试的覆盖率**？传统方法用坐标描述场景，导致相似场景被重复测试。S3C用谓词抽象，将'车在(10.5, -3.2)'转化为'前方近距离有车'，这样就能统计哪些空间配置测过了，哪些没测过。我们在NuScenes上的实验显示，404个场景产生了394种不同配置，98%是长尾场景，这就是S3C要解决的问题。"

### **版本C：对比导向**
> "S3C与传统方法的区别在于**抽象层次**。传统方法关注单个场景的可视化（画BEV图），S3C关注场景空间的覆盖率统计（画热力图）。前者回答'这帧图里有什么'，后者回答'这1000帧图测了哪些场景类型'。我们的实现遵循S3C框架，用4象限×5距离档进行谓词抽象，发现NuScenes的单例聚类达98%，说明真实场景的多样性远超仿真。"

## 🎤 预判老师的追问

### **Q1: "你们为什么不用rustworkx？"**
```
A: "我们优先考虑了工程实用性和可读性。JSON格式便于调试和与
    NuScenes生态集成。但您说得对，rustworkx能提供更强大的图
    查询能力。未来我们计划实现转换接口，在保持JSON易读性的同时，
    支持rustworkx的高级查询功能。"
```

### **Q2: "你们的可视化重点是不是跑偏了？"**
```
A: "确实，我们在汇报准备中过度强调了单帧BEV可视化。实际上我们
    也做了覆盖率统计（聚类分布图），发现了98%单例这个重要现象。
    这正是S3C的核心价值：用统计视角而非单帧视角看测试覆盖。我们
    会调整PPT，突出覆盖率分析的重要性。"
```

### **Q3: "98%单例说明什么？"**
```
A: "说明三点：
    1. 真实世界场景多样性极高（vs CARLA 54%）
    2. 传统的代表性场景采样不适用
    3. 需要S3C这样的系统化覆盖率度量
    
    这也验证了S3C论文的核心观点：自动驾驶测试需要从'测几个
    典型场景'转向'测覆盖整个场景空间'。"
```
