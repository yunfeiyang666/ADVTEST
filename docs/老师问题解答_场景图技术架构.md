## ✅ 问题1：图用什么语言描述？

### **S3C官方的答案**

S3C使用**图论数据结构**来描述场景图，具体是：

#### **数据结构：有向无环图（DAG）**
```python
# 来自 s3c-main/utils/test/test_asg_compare.py
import rustworkx as rx

# 创建场景图
scene_graph = rx.PyDAG()  # PyDAG = Python Directed Acyclic Graph

# 添加根节点（ego车）
ego = scene_graph.add_node('ego')

# 添加子节点和关系（边）
scene_graph.add_child(ego, 'car', 'near')      # ego --(near)--> car
scene_graph.add_child(ego, 'truck', 'left')    # ego --(left)--> truck
scene_graph.add_child(ego, 'pedestrian', 'visible')  # ego --(visible)--> pedestrian
```

#### **节点表示（Nodes）**
```python
# 来自 s3c-main/utils/dataset.py
class Node:
    def __init__(self, name, base_class=None):
        self.name = name            # 节点名称，如 "car", "ego", "pedestrian"
        self.base_class = base_class  # 基类，如 "vehicle", "human"
    
    def __repr__(self):
        return str(self.name)

# 示例
node_ego = Node('ego')
node_car1 = Node('car', base_class='vehicle')
```

#### **边/关系表示（Edges）**
```python
# 边就是节点之间的连接，带有标签
# 标签表示空间关系：

空间关系标签：
├─ 距离关系：near_coll, super_near, very_near, near, visible
├─ 角度关系：left, right, front, rear
├─ 组合关系：near + left = "在左侧且很近"
└─ 车道关系：isIn (在某车道内)
```

### **我们的实现**

我们使用**JSON格式**描述场景图（更易读、更灵活）：

```json
{
  "nodes": [
    {
      "id": "ego",
      "category_name": "vehicle.ego",
      "pose": {"ego": {"center": [0, 0, 0]}},
      "velocity": {"ego": [0, 0, 0]}
    },
    {
      "id": "car_001",
      "category_name": "vehicle.car",
      "pose": {"ego": {"center": [10.5, -3.2, 0]}},
      "bins": {
        "sector8": "front-left",
        "s3c_angular": "direct_front",
        "s3c_distance": "near"
      }
    }
  ],
  "edges": [
    {
      "source": "ego",
      "target": "car_001",
      "relation_type": "ahead",
      "distance": 11.2,
      "ttc": 2.5
    }
  ]
}
```

## ✅ 问题5：图支不支持查询？

### **S3C官方的查询能力**

#### **1. 图同构查询（Isomorphism）**
```python
# 来自 utils/asg_compare.py
import rustworkx as rx

def is_isomorphic(sg1, sg2, timeout=-1):
    """检查两个图是否同构（结构相同）"""
    return rx.is_isomorphic(sg1, sg2)

# 用途：聚类相似场景
for sg in scene_graphs:
    for cluster in clusters:
        if is_isomorphic(sg, cluster[0]):
            cluster.append(sg)
            break
```

#### **2. 图切片查询（Slicing）**
```python
# 来自 approach/README.md

def slice(scene_graph, specification_clause):
    """
    根据规范条件切片图，找到满足条件的子图
    """
    # 示例规范：一辆车在左侧且很近
    clause = {
        "entity": "car",
        "relations": ["left", "near"]
    }
    
    # 遍历图找到匹配的子图
    for node in scene_graph.nodes():
        if matches(node, clause):
            return extract_subgraph(node)
    return None
```

### **我们的查询能力**

```python
# 我们的查询基于JSON遍历

# 1. 节点查询
def find_nodes_by_category(scene_graph, category):
    return [n for n in scene_graph['nodes'] 
            if category in n['category_name']]

# 2. 关系查询
def find_edges_by_relation(scene_graph, relation_type):
    return [e for e in scene_graph['edges'] 
            if e['relation_type'] == relation_type]

# 3. 空间查询
def find_objects_in_sector(scene_graph, sector):
    return [n for n in scene_graph['nodes'] 
            if n.get('bins', {}).get('sector8') == sector]

# 4. 覆盖率查询（S3C签名）
def get_s3c_signature(scene_graph):
    signature = []
    for node in scene_graph['nodes']:
        if node['id'] == 'ego':
            continue
        cat = node['category_name'].split('.')[0]
        ang = node['bins']['s3c_angular']
        dist = node['bins']['s3c_distance']
        signature.append(f"{cat}-{ang}-{dist}")
    return tuple(sorted(signature))
```

## 🎯 给老师的核心回答

### **简洁版**

> "S3C使用**有向无环图（DAG）**来表示场景。节点表示实体（ego、car、pedestrian等），边表示空间关系（near、left等）。底层使用**rustworkx库**（Rust实现的高性能图库），支持**图同构检测**用于聚类，支持**图切片查询**用于规范覆盖率计算。输入是传感器数据（图像、LiDAR），经**RoadScene2Vec场景图生成器**处理后生成`.rsv`文件（pickle格式）。我们的实现则直接用**JSON格式**表示图，更易读但查询能力较弱。"

### **详细版（PPT用）**

#### Slide 1: 场景图的数据结构
```
标题：S3C场景图 = 有向无环图（DAG）

图示：
    ego (自车)
     ├── near ──→ car
     ├── left ──→ truck
     └── visible ──→ pedestrian

技术栈：
• 图库：rustworkx.PyDAG (Rust实现)
• 备选：networkx (Python实现)
• 文件：.rsv (pickle序列化)
```

#### Slide 2: 节点与边的描述
```
节点（Node）:
├─ 属性：name, base_class
├─ 示例：Node('car', 'vehicle')
└─ 包含：实体类型、状态属性

边（Edge）:
├─ 类型：空间关系
├─ 参数：距离档、角度档
└─ 示例：(ego, car, 'near+left')
```

#### Slide 3: 查询能力
```
S3C支持的查询：
1. 图同构检测 → 用于聚类
2. 路径查询 → 检查可达性
3. 图切片 → 规范覆盖率
4. 元数据查询 → 快速过滤

实现库：
• rustworkx.is_isomorphic()
• scene_graph.path_exists()
• scene_graph.induced_subgraph()
```

#### Slide 4: 输入与流程
```
输入：
├─ 相机图像 (6个视角)
├─ LiDAR点云
├─ 传感器标定
└─ 地图信息

流程：
传感器数据 
  ↓
RoadScene2Vec (Detectron2)
  ↓
场景图 (.rsv)
  ↓
S3C聚类与分析
```

## 🔍 我们与S3C的关键差异

### **优势**
1. ✅ **数据格式更易读**：JSON vs pickle
2. ✅ **信息更丰富**：包含完整的NuScenes元数据
3. ✅ **可视化更直观**：BEV图 + 马赛克图

### **劣势**
1. ❌ **查询能力较弱**：字典遍历 vs 图算法
2. ❌ **性能较差**：JSON解析 vs Rust原生
3. ❌ **不支持图同构**：无法直接聚类

### **改进建议**
```python
# 未来可以引入rustworkx
import rustworkx as rx

def convert_to_rustworkx(json_scene_graph):
    """将我们的JSON格式转为rustworkx.PyDAG"""
    sg = rx.PyDAG()
    
    # 添加节点
    node_map = {}
    for node in json_scene_graph['nodes']:
        idx = sg.add_node(node['id'])
        node_map[node['id']] = idx
    
    # 添加边
    for edge in json_scene_graph['edges']:
        sg.add_edge(
            node_map[edge['source']],
            node_map[edge['target']],
            edge['relation_type']
        )
    
    return sg

# 这样就能使用rustworkx的强大查询能力！
```
