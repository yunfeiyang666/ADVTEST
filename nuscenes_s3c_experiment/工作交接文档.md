## 🔧 七、核心技术要点

### 7.1 场景图Schema

```json
{
  "scene_name": "scene-0553",
  "frame": 8,
  "nodes": [
    {
      "unique_id": "ego",
      "type": "ego",
      "translation": [x, y, z]
    },
    {
      "unique_id": "car1",
      "type": "car",
      "status": "moving",        // ⭐ 新增
      "attributes": "moving",    // ⭐ 新增
      "translation": [x, y, z],
      "velocity": [vx, vy, vz]
    }
  ],
  "edges": [
    {
      "source": "ego",
      "target": "car1",
      "predicates": ["front", "near"],  // [方位, 距离]
      "distance": 5.2,
      "angle": 15.3
    }
  ]
}
```

### 7.2 类型映射规则

```python
# config.py中的CATEGORY_MAPPING
'vehicle.trailer': 'truck',      # 拖车 → truck
'vehicle.motorcycle': 'bicycle', # 摩托车 → bicycle  
'movable_object.barrier': 'barrier'  # 护栏 → barrier
```

### 7.3 Status推断逻辑

```python
# status_inference.py
def infer_status(velocity, attributes):
    speed = np.linalg.norm(velocity[:2])
    
    if 'with_rider' in attributes:
        return 'with_rider'
    elif 'without_rider' in attributes:
        return 'without_rider'
    elif speed > 0.5:
        return 'moving'
    else:
        return 'stopped'
```

## ⚠️ 八、已知问题与解决方案

### 8.1 多跳问题 (待解决)

**问题**: 复杂多跳查询Cypher生成失败

```
例: "Is the status of the bus to the back right of the pedestrian 
     the same as the bus to the front of the trailer?"
     
需要: 3跳查询
结果: Cypher生成为空或语法错误
```

**计划方案**:
1. 问题分解器：将复杂问题拆分为多个子查询
2. 多跳模板：预定义2-hop、3-hop Cypher模板

### 8.2 L-路径覆盖 (待实现)

```
L=0: 顶点覆盖 - 测试覆盖所有节点
L=1: 边覆盖 - 测试覆盖所有边（当前已有）
L=2: 边对覆盖 - 测试覆盖所有2跳路径
```
