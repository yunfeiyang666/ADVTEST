## 🔍 **问题1：什么是集合差运算？**

### **集合差的概念：**

```python
# 集合A - 集合B = A中有但B中没有的元素

# 例子：
所有可能的组合（集合A）= {
    ('near', 'front', 'moving', 'Car'),
    ('near', 'front', 'stopped', 'Car'),
    ('near', 'rear', 'moving', 'Car'),
    ('mid', 'front', 'moving', 'Car'),
    ...
    共144种
}

实际存在的组合（集合B）= {
    ('near', 'front', 'moving', 'Car'),
    ('mid', 'front', 'stopped', 'Pedestrian'),
    ...
    共60种
}

盲区（A - B）= {
    ('near', 'rear', 'moving', 'Car'),  # ← A有，B没有
    ('far', 'left', 'stopped', 'Bus'),   # ← A有，B没有
    ...
    共84种
}
```

---

### **集合差运算的作用：**

```
找出"应该有但实际没有"的东西

在我们的项目中：
- 应该有：144种可能的场景配置
- 实际有：60种
- 差集（盲区）：84种

用途：
✓ 识别测试盲区（哪些场景没测过）
✓ 指导数据收集（需要补充哪些场景）
✓ 指导VQA测试（重点测试盲区配置）
```

---

## 🔍 **问题2：为什么Neo4j不能做集合差？**

### **Neo4j的限制：**

```
Neo4j擅长：
✓ 查询已有的数据（"数据库里有什么"）
✓ 图遍历和模式匹配
✓ 统计和聚合

Neo4j不擅长：
❌ 推理不存在的数据（"数据库里没有什么"）
❌ 生成所有可能的组合
❌ 集合差运算

原因：
Neo4j是数据库，不是计算引擎
它只能查询存在的数据
不能推理缺失的数据
```

---

### **举例说明：**

```cypher
// Neo4j可以做：
MATCH (obj:Car)
WHERE obj.size_length > 5
RETURN obj
// → 找出数据库中长度>5米的车

// Neo4j不能做：
// "找出数据库中没有的车"
// "找出应该有但实际没有的配置"
// → 因为数据库不知道"应该有什么"
```

---

### **解决方案：**

```python
# 用Python做集合差

# 1. 在Python中生成所有可能的组合
all_possible = generate_all_combinations()  # 144种

# 2. 从Neo4j查询实际存在的组合
actual = query_from_neo4j()  # 60种

# 3. 在Python中计算差集
uncovered = all_possible - actual  # 84种

# Neo4j负责：查询数据
# Python负责：逻辑推理
```

### **或者在Neo4j中查看"稀有配置"：**

```cypher
// 查询出现次数很少的配置（接近盲区）
MATCH (ego:Ego)-[r:SPATIAL_RELATION]->(obj:Object)
WHERE r.distance IS NOT NULL
  AND r.direction_sector IS NOT NULL

WITH CASE 
        WHEN r.distance < 10 THEN 'near'
        WHEN r.distance < 30 THEN 'mid'
        ELSE 'far'
     END AS distance_level,
     r.direction_sector AS direction,
     CASE WHEN r.moving THEN 'moving' ELSE 'stopped' END AS motion,
     CASE 
        WHEN obj:Pedestrian THEN 'Pedestrian'
        WHEN obj:Car THEN 'Car'
        WHEN obj:Truck THEN 'Truck'
        WHEN obj:Bus THEN 'Bus'
        WHEN obj:Bicycle THEN 'Bicycle'
        WHEN obj:Motorcycle THEN 'Motorcycle'
     END AS object_type

WHERE distance_level IS NOT NULL
  AND object_type IS NOT NULL

RETURN distance_level, direction, motion, object_type, COUNT(*) AS frequency
ORDER BY frequency ASC
LIMIT 20
```

**结果：**
```
frequency = 1 的配置 → 极稀有（接近盲区）
frequency = 2-3 的配置 → 稀有
```

## 🔍 **问题4：热力图怎么生成？**

### **方法1：用Python生成（推荐）**

我帮你创建一个热力图生成脚本：

```python
# step5_generate_heatmap.py

import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from neo4j import GraphDatabase

# 连接Neo4j
NEO4J_URI = "neo4j://localhost:7687"
NEO4J_USER = "neo4j"
NEO4J_PASSWORD = "87017563"

driver = GraphDatabase.driver(NEO4J_URI, auth=(NEO4J_USER, NEO4J_PASSWORD))

# 查询数据
with driver.session() as session:
    result = session.run("""
        MATCH (ego:Ego)-[r:SPATIAL_RELATION]->(obj:Object)
        WHERE r.distance IS NOT NULL
          AND r.direction_sector IS NOT NULL
        
        WITH CASE 
                WHEN r.distance < 10 THEN 'near'
                WHEN r.distance < 30 THEN 'mid'
                ELSE 'far'
             END AS distance_level,
             r.direction_sector AS direction
        
        RETURN distance_level, direction, COUNT(*) AS count
    """)
    
    # 收集数据
    data = {}
    for record in result:
        key = (record['distance_level'], record['direction'])
        data[key] = record['count']

# 创建矩阵
distance_labels = ['near', 'mid', 'far']
direction_labels = ['front', 'rear', 'left', 'right']

matrix = np.zeros((3, 4))

for i, dist in enumerate(distance_labels):
    for j, direction in enumerate(direction_labels):
        matrix[i][j] = data.get((dist, direction), 0)

# 绘制热力图
plt.figure(figsize=(10, 6))

sns.heatmap(
    matrix,
    annot=True,  # 显示数值
    fmt='.0f',  # 整数格式
    cmap='YlOrRd',  # 黄-橙-红配色
    xticklabels=direction_labels,
    yticklabels=distance_labels,
    cbar_kws={'label': 'Number of Objects'},
    linewidths=0.5,
    linecolor='gray'
)

plt.title('Coverage Heatmap: Distance × Direction', 
          fontsize=14, fontweight='bold')
plt.xlabel('Direction Sector', fontsize=12)
plt.ylabel('Distance Level', fontsize=12)
plt.tight_layout()

# 保存
output_path = 'output/figures/coverage_heatmap.png'
plt.savefig(output_path, dpi=300, bbox_inches='tight')
print(f"✓ 热力图已保存: {output_path}")

plt.show()

driver.close()
```
