**现在**：每个对象有独特名称
```json

{"unique_id": "car2", "type": "car"}

```

### **2. 全关系图**

**之前**：只有ego到其他对象
```
ego -> car1
ego -> car2

```

**现在**：所有对象之间的关系

```
ego -> car1, car2, pedestrian1, ...
car1 -> ego, car2, car3, pedestrian1, ...
```

**格式**：`[方位, 距离级别]`

**示例**：

```
ego -> car2: [left, mid] (15.2m)
car1 -> car2: [left, mid] (18.5m)
car1 -> pedestrian1: [rear, near] (5.2m)
```

## 💡 **关键技术点**

### **1. 唯一ID生成逻辑**
```python
type_counters = defaultdict(int)
for obj in objects:
    obj_type = simplify_category(obj['category'])
    type_counters[obj_type] += 1
    unique_id = f"{obj_type}{type_counters[obj_type]}"
    # 结果: car1, car2, pedestrian1, pedestrian2, ...
```

### **2. 全关系生成**
```python
for obj1 in objects:
    for obj2 in objects:
        if obj1 != obj2:
            relation = calculate_relation(obj1, obj2)
            relationships.append(relation)
# 结果: 44个对象 × 43 = 1892条关系
```

### **3. 谓词简化**
```python
# 方位判断
if -45 <= angle < 45: direction = 'front'
elif 45 <= angle < 135: direction = 'left'
elif -135 <= angle < -45: direction = 'right'
else: direction = 'rear'

# 距离判断
if distance <= 10: distance_level = 'near'
elif distance <= 25: distance_level = 'mid'
else: distance_level = 'far'

predicates = [direction, distance_level]
```

### **4. 可视化要点**
- 使用matplotlib绘制
- 不同类型不同颜色
- 节点在线条上层（zorder）
- 透明度表示距离远近
