## 📚 **LDFuzz的覆盖率计算方法**

### **Coverage 1: 空间覆盖率（面积）**

```python
# 来自 LDFuzz/utils/coverage_utils.py

def get_coverage1_DUMPSver(DUMPS, error=False) -> float:
    """
    计算空间覆盖率
    
    公式：
    Coverage1 = 对象覆盖的面积 / 道路总面积
    
    分子：所有对象的多边形面积之和
    分母：道路的凸包面积
    """
    a, b = 0, 0
    
    for scene in DUMPS['scene']:
        hull = DUMPS['scene'][scene]['road_hull']  # 道路凸包（分母）
        polygon = DUMPS['scene'][scene]['gt_polygon']  # 对象多边形（分子）
        
        a += polygon.area  # 累加对象面积
        b += hull.area     # 累加道路面积
    
    return a / b  # 覆盖率 = 对象面积/道路面积
```

**LDFuzz的Coverage1特点：**
- ✅ 有明确的分母（道路面积）
- ✅ 有明确的分子（对象面积）
- ✅ 返回百分比
- ❌ 但是基于面积，不是场景配置

### **Coverage 2: 场景图覆盖率（配置）**

```python
# 来自 LDFuzz/utils/coverage_utils.py

def get_coverage2_DUMPSver(DUMPS, error=False) -> float:
    """
    计算场景图覆盖率
    
    公式：
    Coverage2 = 实际聚类数 / 理论可能的聚类数
    
    分子：实际存在的场景图聚类数
    分母：理论上所有可能的场景图配置数
    """
    sg, tot_sg = 0, 0
    
    for sg_type in DUMPS['cluster']:
        # 实际聚类数（分子）
        sg += len(DUMPS['cluster'][sg_type]['cluster'])
        
        # 理论聚类数（分母）
        # 2^n × (天气类型+1)
        # n = 场景图类型的二进制位数
        tot_sg += (2**bin(sg_type).count('1')) * (len(scene_level) + 1)
    
    return sg / tot_sg  # 覆盖率
```

**LDFuzz的Coverage2特点：**
- ✅ 有明确的分母（理论聚类数）
- ✅ 有明确的分子（实际聚类数）
- ✅ 返回百分比
- ✅ 基于场景配置（和我们类似）

**分母的计算方式：**
```
理论聚类数 = 2^(区域数) × (天气类型+1)

例如：
6个区域，4种天气
→ 2^6 × (4+1) = 64 × 5 = 320种可能的配置
```

## 📚 **S3C论文的覆盖率计算方法**

### **S3C的覆盖率定义：**

```python
# S3C论文中的覆盖率（推测，基于论文描述）

def s3c_coverage(test_set, specification):
    """
    S3C覆盖率
    
    公式：
    Coverage = 符合规范的等价类数量
    
    不是百分比，而是绝对数量！
    """
    # 1. 聚类场景图
    clusters = cluster_scene_graphs(test_set)
    
    # 2. 筛选符合规范的聚类
    matching_clusters = [c for c in clusters if matches(c, specification)]
    
    # 3. 返回数量（不是百分比）
    return len(matching_clusters)
```

**S3C的特点：**
- ❌ **没有明确的分母**
- ✅ 返回等价类数量
- ✅ 用于对比不同测试集
- ❌ 不是传统意义的"覆盖率"

**S3C关注的是：**
```
不是"覆盖了多少百分比"
而是"发现了多少种不同的场景配置"

例如：
测试集A：394种配置
测试集B：200种配置
→ A的多样性更高
```

## 🎯 **我们应该采用的方法**

### **借鉴LDFuzz Coverage2的思路：**

```python
# 我们的覆盖率API设计

class CoverageAPI:
    """
    覆盖率计算API
    
    提供标准化的覆盖率计算接口
    """
    
    def __init__(self, neo4j_driver):
        self.driver = neo4j_driver
        
        # ===== 定义覆盖空间（分母）=====
        self.distance_levels = ['near', 'mid', 'far']  # 3种
        self.directions = ['front', 'rear', 'left', 'right']  # 4种
        self.motions = ['moving', 'stopped']  # 2种
        self.types = ['Pedestrian', 'Car', 'Truck', 'Bus', 'Bicycle', 'Motorcycle']  # 6种
        
        # 理论总数（分母）
        self.total_combinations = 3 × 4 × 2 × 6 = 144
    
    # ===== API 1: 计算覆盖率 =====
    def calculate_coverage(self):
        """
        API: 计算覆盖率
        
        返回：
            coverage_rate: 覆盖率（0-1之间的浮点数）
        """
        actual = self._query_actual_combinations()
        return len(actual) / self.total_combinations
    
    # ===== API 2: 识别盲区 =====
    def identify_blind_spots(self):
        """
        API: 识别覆盖盲区
        
        返回：
            uncovered: 未覆盖的组合列表
        """
        all_possible = self._generate_all_combinations()
        actual = self._query_actual_combinations()
        return all_possible - actual
    
    # ===== API 3: 生成热力图 =====
    def generate_heatmap(self, output_path):
        """
        API: 生成覆盖率热力图
        
        参数：
            output_path: 输出文件路径
        """
        data = self._query_coverage_matrix()
        self._plot_heatmap(data, output_path)
    
    # ===== 内部方法：查询实际组合 =====
    def _query_actual_combinations(self):
        """查询实际存在的组合"""
        with self.driver.session() as session:
            result = session.run("""
                MATCH (ego)-[r]->(obj)
                RETURN DISTINCT 
                    CASE 
                        WHEN r.distance < 10 THEN 'near'
                        WHEN r.distance < 30 THEN 'mid'
                        ELSE 'far'
                    END AS distance,
                    r.direction_sector AS direction,
                    CASE WHEN r.moving THEN 'moving' ELSE 'stopped' END AS motion,
                    CASE 
                        WHEN obj:Pedestrian THEN 'Pedestrian'
                        WHEN obj:Car THEN 'Car'
                        WHEN obj:Truck THEN 'Truck'
                        WHEN obj:Bus THEN 'Bus'
                        WHEN obj:Bicycle THEN 'Bicycle'
                        WHEN obj:Motorcycle THEN 'Motorcycle'
                    END AS type
            """)
            
            combinations = set()
            for record in result:
                if all([record['distance'], record['direction'], 
                       record['motion'], record['type']]):
                    combo = (record['distance'], record['direction'], 
                            record['motion'], record['type'])
                    combinations.add(combo)
            
            return combinations
    
    # ===== 内部方法：生成所有可能组合 =====
    def _generate_all_combinations(self):
        """生成所有可能的组合"""
        all_combos = set()
        for dist in self.distance_levels:
            for direction in self.directions:
                for motion in self.motions:
                    for obj_type in self.types:
                        all_combos.add((dist, direction, motion, obj_type))
        return all_combos
```
