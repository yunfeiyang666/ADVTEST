# 真正的覆盖率计算原理

## 🎯 **核心问题**

### **step4做了什么？**
```
统计了实际存在的配置数量（分子）
- 55种配置
- 但没有分母！
```

### **真正的覆盖率需要什么？**
```
覆盖率 = 实际覆盖的组合数 / 理论总组合数
        (分子)              (分母)
```

---

## 📊 **覆盖率计算详解**

### **第1步：定义覆盖空间（分母）**

#### **我们定义的场景特征空间：**

```python
# 维度1：距离等级（3档）
distance_levels = ['near', 'mid', 'far']
# near: 0-10m
# mid: 10-30m
# far: >30m

# 维度2：方向扇区（4档）
direction_sectors = ['front', 'rear', 'left', 'right']

# 维度3：运动状态（2种）
motion_states = ['moving', 'stopped']

# 维度4：对象类型（6种）
object_types = ['Pedestrian', 'Car', 'Truck', 'Bus', 'Bicycle', 'Motorcycle']

# 理论总组合数（分母）
total_combinations = 3 × 4 × 2 × 6 = 144种
```

#### **这144种组合是什么？**

```
组合1: Pedestrian + near + front + moving
组合2: Pedestrian + near + front + stopped
组合3: Pedestrian + near + rear + moving
组合4: Pedestrian + near + rear + stopped
...
组合144: Motorcycle + far + right + stopped

每一种组合 = 一个"场景原子"
```

---

### **第2步：查询实际覆盖（分子）**

#### **从Neo4j查询实际存在的组合：**

```cypher
MATCH (ego:Ego)-[r:SPATIAL_RELATION]->(obj:Object)
RETURN DISTINCT 
    CASE 
        WHEN r.distance < 10 THEN 'near'
        WHEN r.distance < 30 THEN 'mid'
        ELSE 'far'
    END AS distance_level,
    r.direction_sector AS direction,
    CASE WHEN r.moving THEN 'moving' ELSE 'stopped' END AS motion,
    CASE 
        WHEN obj:Pedestrian THEN 'Pedestrian'
        WHEN obj:Car THEN 'Car'
        WHEN obj:Truck THEN 'Truck'
        WHEN obj:Bus THEN 'Bus'
        WHEN obj:Bicycle THEN 'Bicycle'
        WHEN obj:Motorcycle THEN 'Motorcycle'
    END AS object_type
```

#### **假设查询结果：**

```
实际存在的组合（举例）：
1. Pedestrian + near + front + stopped
2. Pedestrian + mid + front + moving
3. Car + near + front + moving
4. Car + mid + right + stopped
...
45. Motorcycle + far + front + stopped

实际覆盖数（分子）= 45种
```

---

### **第3步：计算覆盖率**

```python
覆盖率 = 实际覆盖数 / 理论总数
      = 45 / 144
      = 0.3125
      = 31.25%

未覆盖率 = 1 - 覆盖率
        = 68.75%

未覆盖组合数 = 144 - 45 = 99种
```

---

### **第4步：识别覆盖盲区**

#### **哪些组合没有覆盖？**

```python
# 所有可能的144种组合
all_combinations = {
    ('Pedestrian', 'near', 'front', 'moving'),
    ('Pedestrian', 'near', 'front', 'stopped'),
    ...
    ('Motorcycle', 'far', 'right', 'stopped')
}

# 实际覆盖的45种
actual_combinations = {
    ('Pedestrian', 'near', 'front', 'stopped'),
    ('Car', 'mid', 'right', 'stopped'),
    ...
}

# 未覆盖的99种（盲区）
uncovered = all_combinations - actual_combinations

# 例如：
# ('Motorcycle', 'near', 'rear', 'moving') ← 没有数据
# ('Bus', 'far', 'left', 'stopped') ← 没有数据
# ...
```

---

### **第5步：生成覆盖率热力图**

#### **热力图矩阵（距离×方向）：**

```
        front  rear  left  right
near     15     8     5     12     ← 有数据的格子
mid      20     6     3     10
far      8      2     0     1      ← 0表示没有数据（盲区）

颜色：
- 深色：数据多（覆盖好）
- 浅色：数据少
- 白色：无数据（盲区）
```

```python

# 6. 生成热力图

```
