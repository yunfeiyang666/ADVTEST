## 📖 **步骤1：数据加载（step1_data_loading.py）**

**目标：** 从NuScenes数据集中提取原始场景信息

**输入：**

```
- 404个关键帧
- 复杂的JSON格式
```

**处理过程：**
```python
1. 加载NuScenes数据集
   nusc = NuScenes(version='v1.0-mini', ...)
   
2. 遍历每个场景
   for scene in nusc.scene:
```

```
output/raw_scenes_data.json

- 328个对象（包含barrier等）
- 标准化的JSON格式
```

## 📖 **步骤2：场景图生成（step2_scene_graph_generation_enhanced.py）**

### **这一步在做什么？**

**目标：** 将原始数据转换为结构化的场景图

**输入：**
```
output/raw_scenes_data.json（步骤1的输出）
- 全局坐标系的位置
- 连续的数值
- 详细的类别名称
```

**处理过程：**
```python
1. 读取步骤1的JSON文件
   
2. 对每个场景：
   
   2.1 计算相对位置
       ego在 [411.30, 1180.89]
       car在 [353.79, 1132.36]
       ↓
       相对位置 = car - ego
       ↓
       转换到ego坐标系
       ↓
       rel_pos = [65.42, -37.19, 0.6]
   
   2.2 计算距离和角度
       distance = sqrt(65.42² + 37.19²) = 75.25米
       angle = atan2(-37.19, 65.42) = -29.6度
   
   2.3 评估S3C谓词
       distance = 75.25米 → 超出25米 → 无距离等级
       angle = -29.6度 → 在-45°~+45°范围 → "front"
       speed = 0.04 m/s → <0.5 → "stopped"
       ↓
       predicates = ["front", "stopped"]
   
   2.4 简化类别
       "vehicle.car" → "car"
       "human.pedestrian.adult" → "pedestrian"
   
   2.5 构建场景图
       nodes: [ego, car, pedestrian, ...]
       edges: [
         ego → car: {predicates: ["front", "stopped"], distance: 75.25, ...}
       ]
   
3. 保存场景图（包含15类信息）
```

**输出：**
```
output/scene_graphs/all_scene_graphs_enhanced.json
- 10个场景图
- 283个对象（过滤了barrier等）
- 每个对象包含：
  * S3C谓词（核心）
  * 精确数值（距离、角度、速度）
  * 对象属性（尺寸、类别）
  * 质量指标（点云数量）
```

**关键代码：**

**为什么要这一步？**
- 从全局坐标 → 相对坐标（符合人类认知）
- 从连续数值 → 离散谓词（便于聚类）

## 📖 **步骤3：Neo4j导入（step3_neo4j_import.py）**

### **这一步在做什么？**

**目标：** 将场景图导入Neo4j图数据库

**输入：**
```
output/scene_graphs/all_scene_graphs_enhanced.json（步骤2的输出）
- JSON格式的场景图
```

**处理过程：**
```python
1. 连接Neo4j数据库
   driver = GraphDatabase.driver("neo4j://localhost:7687", ...)
   
2. 清空旧数据
   MATCH (n) DETACH DELETE n
   
3. 创建约束和索引
   CREATE CONSTRAINT scene_token ...
   CREATE INDEX object_id ...
   
4. 对每个场景：
   
   4.1 创建Scene节点
       CREATE (scene:Scene {
         token: "...",
         name: "scene-0061",
         total_objects: 43,
         min_distance: 3.11,
         ...
       })
   
   4.2 创建Ego节点
       CREATE (ego:Ego {
         id: "ego_cc8c0bf5",
         position_x: 411.30,
         ...
       })
   
   4.3 创建对象节点
       CREATE (car:Object:Car {
         id: "car_...",
         size_width: 2.01,
         size_length: 4.63,
         ...
       })
   
   4.4 创建关系
       CREATE (scene)-[:CONTAINS]->(ego)
       CREATE (scene)-[:CONTAINS]->(car)
       CREATE (ego)-[:SPATIAL_RELATION {
         predicates: ['front', 'stopped'],
         distance: 75.25,
         angle: -29.6,
         ...
       }]->(car)
   
5. 验证导入结果
   统计节点和关系数量
```

**输出：**
```
Neo4j数据库中的数据：
- 303个节点（10 Scene + 10 Ego + 283 Object）
- 576条关系（293 CONTAINS + 283 SPATIAL_RELATION）
```

**关键代码：**
```python
def import_scene(self, scene_data):
    # 创建场景节点
    session.run("CREATE (scene:Scene {...})")
    
    # 创建ego节点
    session.run("CREATE (ego:Ego {...})")
    
    # 创建对象节点和关系
```

## 📖 **步骤4：覆盖率分析（step4_coverage_analysis.py）**

### **这一步在做什么？**

**目标：** 使用Cypher查询计算覆盖率和识别关键场景

**输入：**
```
Neo4j数据库（步骤3导入的数据）
- 303个节点
- 576条关系
```

**处理过程：**
```python
1. 连接Neo4j数据库
   
2. C1覆盖率查询（空间配置多样性）
   MATCH (ego)-[r]->(obj)
   RETURN DISTINCT 
     r.distance_level,
     r.direction_sector,
     obj.type,
     COUNT(*) AS frequency
   
   → 统计有多少种独特的(距离, 方向, 对象类型)组合
   → 结果：55种配置
   
3. C2覆盖率查询（场景结构多样性）
   MATCH (scene)-[:CONTAINS]->(ego)
   MATCH (ego)-[r]->(obj)
   WITH scene, collect({...}) AS structure
   RETURN scene, structure
   
   → 统计每个场景的完整结构
   → 结果：10个场景
   
4. 长尾场景识别
   WITH structure, collect(scene) AS scenes
   WHERE size(scenes) = 1
   RETURN scenes
   
   → 找出只出现1次的场景配置
   → 结果：10个长尾场景（100%长尾率）
   
5. 危险场景识别
   MATCH (scene:Scene)
   WHERE scene.min_distance < 5
   RETURN scene
   
   → 找出最小距离<5米的场景
   → 结果：2个危险场景
   
6. 保存分析报告
   保存为JSON文件
```

**输出：**
```
output/statistics/step4_coverage_analysis.json
- C1覆盖率：55种配置
- C2覆盖率：10个场景
- 长尾场景：10个
- 危险场景：2个
- 高速场景：2个
```

**关键代码：**
```python
def calculate_c1_coverage(self):
    # Cypher查询
    result = session.run("""
        MATCH (ego)-[r]->(obj)
        RETURN DISTINCT 
          r.distance_level,
          r.direction_sector,
          labels(obj)[1] AS type,
          COUNT(*) AS frequency
    """)
    
    # 处理结果
    configs = []
    for record in result:
        configs.append({
            'distance': record['distance'],
            'direction': record['direction'],
            'object_type': record['type'],
            'frequency': record['frequency']
        })
    
    return len(configs)  # C1覆盖率
```

**为什么要这一步？**
- 计算场景多样性（覆盖率）
- 识别测试盲区（长尾场景）
- 识别高风险场景（危险场景）
- 指导VQA测试策略
